# Kom i gang

## Krav

En webbrowser. Der er intet byggetrin, ingen pakke og ingen server.

## Hent filerne

```bash
git clone https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/041-web-movie-ranking.git
cd 041-web-movie-ranking
```

## Åbn siden

Dobbeltklik på `src/index.html`, eller kør en af disse kommandoer:

```bash
# Windows
start src/index.html
# macOS
open src/index.html
# Linux
xdg-open src/index.html
```

Du skulle gerne se siden nedenfor.
