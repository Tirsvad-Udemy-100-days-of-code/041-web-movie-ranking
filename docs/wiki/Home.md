# Home

A plain HTML page that ranks my top 3 movies of all time. It is my solution to Day 41 of Udemy's "100 Days of Code: The Complete Python Pro Bootcamp", the project "The Favorite Movie Project".

![The Best Movies According to Tirsvad](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/041-web-movie-ranking/raw/branch/main/docs/images/favorite-movie-page.jpg)

The page has a title (`h1`), a subtitle (`h2`), a horizontal rule (`hr`), and three movies, each an `h3` followed by a `p` with the reason. There is no code to build and nothing to install.

Pages:

- [Getting started](Getting-Started): open the page in a browser.
- [Usage](Usage): what is on the page and how to change the movies.
- [Development](Development): folders, checks, branches and workflows.
