# Getting started

## Requirements

A web browser. There is no build step, no package and no server.

## Get the files

```bash
git clone https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/041-web-movie-ranking.git
cd 041-web-movie-ranking
```

## Open the page

Double-click `src/index.html`, or run one of these commands:

```bash
# Windows
start src/index.html
# macOS
open src/index.html
# Linux
xdg-open src/index.html
```

You should see the page below.
