# Bermula

## Keperluan

Sebuah pelayar web. Tiada langkah binaan, tiada pakej dan tiada pelayan.

## Dapatkan fail

```bash
git clone https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/041-web-movie-ranking.git
cd 041-web-movie-ranking
```

## Buka halaman

Klik dua kali `src/index.html`, atau jalankan salah satu arahan ini:

```bash
# Windows
start src/index.html
# macOS
open src/index.html
# Linux
xdg-open src/index.html
```

Anda patut melihat halaman di bawah.
